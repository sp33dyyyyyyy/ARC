# Sky Climbers (Roblox)

Climb telecom towers and skyscrapers. Climbing burns stamina, platforms let you
catch your breath, and running out means you black out and ragdoll to the
ground. Peaks pay cash and bump your **Tower climbs** counter; spend cash on
boosts to take on the harder, better-paying skyscrapers.

## Open it

**Ready-made place file:** open `build/SkyClimbers.rbxlx` in Roblox Studio and
press **Play**. The world (plaza, roads and all seven towers) is generated by
the server when the game starts, so it appears once you hit Play.

- To keep the towers in the place for editing, press Play, then in the
  Explorer copy `Workspace.World` and `Workspace.Towers`, stop, and paste them
  into Workspace. The server reuses them instead of rebuilding.
- Saving progress needs a published place with **Game Settings > Security >
  Enable Studio Access to API Services** on. Without it the game still runs and
  tells you progress won't save.

**From source with Rojo 7:** `rojo build default.project.json -o build/SkyClimbers.rbxlx`,
or `rojo serve` and connect from the Studio plugin.

## Controls

| Key | Action |
|---|---|
| Walk into a yellow ladder | Climb |
| B (or the stall in the plaza) | Shop |
| C | Use chalk (halves drain for 12s) |
| R | Ragdoll / get up |
| P | Back to the plaza |
| E at a summit lift | Ride down |

## Towers

| Tower | Height | Drain | Payout |
|---|---|---|---|
| Small Mast (x2) | 80 | 1x | $50 |
| Lattice Tower (x2) | 200 | 1.5x | $200 |
| Skyscraper (x2) | 400 | 2.5x, slippery | $1,000 |
| Supertall | 800 | 4x, slippery | $5,000 |

Telecom towers are modelled on self-supporting lattice towers: four tapering
legs, X-bracing, stacked sections with railed rest platforms, dishes, panel
antennas, and a blinking aviation light. Skyscrapers are stepped-setback glass
towers in the style of the Burj Khalifa: every setback is a ledge to rest on,
and each section's ladder sits on a different face, so you walk the ledge to
find the next one. Skyscrapers have no railings.

## Features

- Stamina with hang drain, recovery on solid ground, a low-breath screen
  effect, blackout and ragdoll falls with height-based fall damage
- Boosts: Endurance, Deep Breaths, Quick Hands, Sticky Gloves, Rubber Bones
- Chalk consumable, wind gusts (with warning) that can blow tired climbers off
- Checkpoints on platforms and ledges, summit service lifts
- `Tower climbs: N` counter, summit banner and confetti, leaderstats,
  all-time leaderboard board, daily streak reward, unlockable trails
- Day/night cycle with street lights and blinking aviation lights
- DataStore saving with retries, session locking, and no save after a failed load

## Layout

```
src/shared   Config (all tuning), Rules (pure game logic), Remotes
src/server   Main, WorldBuilder, TowerBuilder, Build, DataService,
             ClimbService, RagdollService, ShopService,
             EnvironmentService, LeaderboardService
src/client   Main, ClimbController, Effects, UI/{Theme,Components,Hud,Overlay,Shop}
tests        run.lua (rules unit tests), geometry/ (tower climbability check)
```

## Checks

```
luau tests/run.lua                          # 15 unit tests for the game rules
python3 tests/geometry/run_geometry.py      # runs the real builders against a Roblox mock
                                            # and verifies every ladder is climbable
```

Stamina runs on the client, because only the owning client knows its exact
climbing state each frame. That only affects the player's own challenge. Cash,
climbs, purchases, payouts and fall damage are all decided on the server.
